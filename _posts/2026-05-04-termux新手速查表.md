## 一、⚠️ 先分清两个提示符（新手最容易踩坑）

| 提示符 | 状态 | 能干什么 | 退出/操作 |
|--------|------|----------|-----------|
| `~ $` | 正常 Termux 终端 | 执行所有 Linux、装软件、跑脚本 | 正常使用即可 |
| `>>>` | Python 交互模式 | 只能写 Python 代码，**不能输系统命令** | 输入 `exit()` 回车退出 |

---

## 二、📁 目录切换常用命令
pwd          # 查看当前所在文件夹路径
ls           # 列出当前目录所有文件/文件夹
cd 文件夹名   # 进入指定文件夹
cd ..        # 返回上一级目录
cd ~         # 回到 Termux 家目录
cd /sdcard   # 进入手机内部存储根目录
---

三、📄 文件 & 文件夹管理
mkdir 文件夹名    # 新建空文件夹
rm 文件名         # 删除单个文件
rm -r 文件夹名    # 强制删除整个文件夹（含内部所有文件）
cp 源文件 目标    # 复制文件
mv 旧名 新名     # 重命名文件 / 移动文件位置
cat 文件名        # 直接查看文件全部内容
nano 文件名       # 编辑文本文件
nano 编辑快捷键
保存：Ctrl+O → 回车
退出：Ctrl+X

---
四、📦 Termux 软件安装卸载核心
pkg update && pkg upgrade   # 更新软件源+升级所有包
pkg install 包名             # 安装软件
pkg remove 包名              # 卸载软件

pkg autoremove               # 清理无用残留依赖
pkg clean                    # 清理安装缓存

---
五、🐍 Python 专属常用
python              # 进入 Python 交互模式
python xxx.py       # 运行 Python 脚本

pip install 库名    # 装 Python 模块
pip cache purge     # 清理 pip 缓存（安全，不删软件）

---
六、⚙️ Termux 必做基础配置
termux-setup-storage   # 获取手机存储权限（必须）
touch ~/.hushlogin     # 关闭多余提示，终端干净清爽
clear                  # 清屏

---
七、✅ 新手切记：Termux 现实情况
- Termux 不是完整 Linux 桌面系统
- 图形、音频、播放器驱动都阉割，不要瞎折腾播放器
- 听歌只用 mpv，最简最稳
- 不要装 X11、桌面、显卡相关包，只会臃肿
- 你的用途：Alist + 本地模型 + 听歌，越精简越稳
