Termux 新手 Linux 命令速查表（极简随身备忘录）
适用：零基础新手、没用过 Linux、只用 Termux 跑 Alist / 本地模型 / 听歌 / 跑脚本
特点：只留常用、够用、必背命令，不废话、不花哨，随用随查。

---
一、⚠️ 先记住两个提示符（最容易搞错）
提示符
状态
能做什么
操作
~ $
✅ 正常 Termux 终端
所有 Linux 命令、装软件、运行脚本
正常使用
>>>
❌ 进入 Python 交互模式
只能写 Python 代码，不能输系统命令
exit() 退出

---
二、📁 文件夹目录常用（最常用）
pwd          # 查看我现在在哪个文件夹
ls           # 查看当前文件夹里有什么
cd 名字      # 进入某个文件夹
cd ..        # 返回上一级
cd ~         # 回到 Termux 主页
cd /sdcard   # 进入手机内部存储

---
三、📄 文件 & 文件夹管理
mkdir 文件夹名    # 新建文件夹
rm 文件名         # 删除文件
rm -r 文件夹名    # 删除整个文件夹（强制删除）
cp 源 目标        # 复制文件
mv 旧名 新名     # 重命名 / 移动文件
cat 文件名        # 查看文件内容
nano 文件名       # 编辑文件
nano 快捷键：
保存：Ctrl+O → 回车
退出：Ctrl+X

---
四、📦 Termux 软件安装卸载核心
pkg update && pkg upgrade   # 更新全部软件
pkg install 包名             # 安装软件
pkg remove 包名              # 卸载软件

pkg autoremove               # 清理无用残留依赖
pkg clean                    # 清理安装缓存

---
五、🐍 Python 专属常用
python              # 进入 Python 交互模式
python xxx.py       # 运行 Python 脚本

pip install 库名    # 装 Python 模块
pip cache purge     # 清理 pip 缓存（安全，不删软件）

---
六、⚙️ Termux 必做基础配置
termux-setup-storage   # 获取手机存储权限（必须）
touch ~/.hushlogin     # 关闭多余提示，终端干净清爽
clear                  # 清屏

---
七、✅ 新手切记：Termux 现实情况
- Termux 不是完整 Linux 桌面系统
- 图形、音频、播放器驱动都阉割，不要瞎折腾播放器
- 听歌只用 mpv，最简最稳
- 不要装 X11、桌面、显卡相关包，只会臃肿
- 你的用途：Alist + 本地模型 + 听歌，越精简越稳
