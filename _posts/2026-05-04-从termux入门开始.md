适用人群：从没接触过 Linux，只用 Termux 跑 Alist、本地迷你大模型、后台听歌的新手自用记录。

---
一、前言
很多人以为 Termux 就是完整版 Linux，其实不是。
Termux 本质是安卓沙箱里的精简命令行环境，不是桌面 Linux，音频、图形、驱动都做了阉割，适合：
- ✅ 本地跑迷你大模型
- ✅ 搭建 Alist 私有网盘
- ✅ 后台挂命令行音乐听歌
- ✅ 练简单 Linux 命令、跑脚本
不适合：装桌面、玩图形界面、折腾复杂多媒体。
本文记录自己从零开始学 Termux 常用命令，极简够用，不折腾、不瞎装包。

---
二、先分清两个关键模式（新手最容易搞错）
1、正常终端模式（可用 Linux 命令）
提示符：~ $
在这里可以输所有 Termux、Linux、安装软件、运行 Python 脚本命令。
2、Python 交互模式（只能写 Python 代码）
提示符：>>>
进到这里就不能输 python xxx.py，会报错：NameError。
退出 Python 交互模式命令：
exit()

---
三、Termux 必学基础命令（日常够用全覆盖）
1、目录查看与切换
pwd          # 查看当前所在文件夹路径
ls           # 列出当前文件夹所有文件
cd 文件夹名   # 进入指定文件夹
cd ..        # 退回上一级文件夹
cd ~         # 回到 Termux 主目录
2、文件和文件夹操作
mkdir 文件夹名     # 新建文件夹
rm 文件名          # 删除单个文件
rm -r 文件夹名     # 删除整个文件夹（连带里面所有内容）
cp 源文件 目标位置  # 复制文件
mv 旧名称 新名称   # 重命名 / 移动文件位置
3、查看和编辑文件
cat 文件名        # 直接查看文件全部内容
nano 文件名       # 编辑文件
clear             # 清屏
nano 编辑快捷键：
保存：Ctrl+O 回车
退出：Ctrl+X

---
四、软件安装、卸载、清理瘦身命令（Termux 核心）
1、更新软件源
pkg update && pkg upgrade
2、安装和卸载软件
pkg install 包名       # 安装软件
pkg remove 包名        # 卸载软件
3、系统瘦身、清理垃圾（必做）
pkg autoremove   # 卸载没用的残留依赖
pkg clean        # 清理系统安装缓存

---
五、Python 相关常用命令
python              # 进入 Python 交互模式
python xxx.py       # 运行 Python 脚本
pip install 库名    # 安装 Python 依赖库
pip cache purge     # 清理 pip 安装缓存（只删垃圾，不删已装库）

---
六、Termux 专属重要配置
1、获取手机存储权限（必装）
termux-setup-storage
2、访问手机内部 SD 卡目录
cd /sdcard
3、关闭多余提示，精简终端
touch ~/.hushlogin

---
七、Termux 使用心得总结
- Termux 不是完整桌面 Linux，音频、图形界面先天阉割，别折腾轻量化播放器，适配很差。
- 听歌老老实实只用 mpv，是 Termux 里最稳、唯一能用的方案。
- 不要乱装 GUI、显卡、桌面相关包，只会变臃肿。
- 自己核心需求就三个：Alist 网盘 + 本地小模型 + 后台听歌，其他全部精简卸载。
- 不用死记命令，用一个熟一个，慢慢就上手 Linux 基础了。
