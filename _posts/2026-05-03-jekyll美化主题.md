Jekyll 博客美化主题一键更换教程｜GitHub Pages 极简换肤，不用本地环境，超好看

前言
刚搭建好的 Jekyll 默认主题特别简陋，黑乎乎不好看。
很多人以为换博客主题很难，要装环境、改代码、折腾部署。
其实 Jekyll 换主题超级简单，全程手机浏览器 GitHub 网页操作，两分钟搞定。
这篇教程教你：一键替换好看 Jekyll 主题、配置头像、侧边栏、文章目录、首页美化，博客瞬间高级感拉满。

---
一、Jekyll 换主题原理（一看就懂）
Jekyll 所有外观，只靠一个文件控制：
_config.yml
默认自带主题是：minima（很丑）
我们只需要：
1. 选一个好看的 Jekyll 主题
2. 改一行配置
3. 提交 GitHub 自动生效
不用改代码、不用重装、不用电脑。

---
二、推荐3个极简又好看 Jekyll 主题
我给你选好适合写笔记、技术博客、简洁干净、加载快的主题，直接复制就能用。
1. cayman（简约纯白高级风，推荐首选）
干净、清爽、阅读舒服，适合技术笔记、教程归档。
2. hacker（极客黑风格，折腾博主必备）
黑色背景、代码感强，适合 Termux、Linux、折腾手记。
3. slate（暗色简约商务风）
低调耐看，颜值高，长期写博客不疲劳。

---
三、网页端一键更换主题（核心步骤）
1. 进入你的博客仓库
打开你的：用户名.github.io 仓库
2. 编辑 _config.yml 文件
找到文件 → 点击编辑按钮（铅笔图标）
3. 修改 theme 这一行
原来默认是：
theme: minima
换成你想要的主题，三选一：
✅ 简约纯白推荐：
theme: cayman
✅ 极客黑色折腾风：
theme: hacker
✅ 暗色商务简约风：
theme: slate
4. 直接提交保存
拉到最下面，点击 Commit changes 提交。

---
四、等待1分钟，博客自动美化完成
GitHub 会自动重新编译博客。
等待 1分钟，刷新你的博客地址：
https://你的用户名.github.io
样式直接大变好看，完美美化完成！

---
五、主题额外美化小配置（可选加分）
在 _config.yml 里面顺带改一下博客信息，更好看。
title: 我的折腾技术博客
description: Termux | Alist | 建站 | 笔记记录分享
baseurl: ""
url: "https://你的用户名.github.io"


---
六、以后想换主题怎么办？
超级简单：
1. 重新编辑 _config.yml
2. 改一下 theme 名字
3. 提交自动换肤
想换就换，一秒切换风格。

---
结语
Jekyll 博客不用花钱、不用服务器、不用复杂操作，改一行代码就能颜值拉满。
