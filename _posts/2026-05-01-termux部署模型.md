# 部署步骤
### 全程无需手机 Root，原生 Termux 完美适配
### 绕过官方安装脚本权限坑，清华源镜像极速下载
### 后台静默驻留不刷屏，一键拉起 AI 对话即用
### 轻量模型低内存流畅运行，安卓手机离线本地 AI

安卓无 Root 部署本地 AI 极简教程，基于 Termux+Ollama，一步避权限坑，离线轻量模型即装即用，新手也能一键搭建私人智能对话助手。

Ollama 是一款极简本地大模型部署工具，依托 Termux 无需手机 Root，一键避开权限报错，离线轻量化 AI 模型秒搭建私人智能对话助手。

- [下载termux清华源](https://mirrors.tuna.tsinghua.edu.cn/fdroid/repo/com.termux_1002.apk)
- 1.更新基础包
```
pkg update -y
pkg upgrade -y
```
- 2.安装ollama
```
pkg install root-repo -y
pkg install ollama -y
```
- 3.启动模型（第一次先会下载）
```
ollama serve & sleep 2 && ollama run qwen2.5:0.5b
```
- 退出对话按 Ctrl+D
- 性能不好的把＂sleep 2＂改4或以上，延时大点让手机有反应时间
