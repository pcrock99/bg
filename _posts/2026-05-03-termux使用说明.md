Termux 超全使用教程｜安卓免 Root 变身随身 Linux 开发机

前言
很多人以为 Linux 只能在电脑上用，其实你的安卓手机，不用刷机、不用 Root、不用破解，装一个 Termux 就能直接拥有完整 Debian 风格 Linux 环境。
手机可以写代码、跑 Python、搭网站、挂脚本、SSH 远程连接、做爬虫、跑编译，随时随地随身服务器。
这篇教程是从零入门到进阶实用全覆盖，新手照着一步步操作即可，一次配置，永久好用。

---
一、Termux 是什么？
Termux 是安卓平台上一款开源、免 Root、纯终端 Linux 模拟器。
简单理解：
- 不需要手机解锁刷机
- 不需要 Root 权限
- 自带完整 Linux 包管理
- 支持 GCC、Python、Node、Git、SSH、数据库、网页服务等
- 后台可挂脚本、常驻运行程序
手机瞬间变成一台便携微型 Linux 工作站。

---
二、正确安装 Termux（避坑必看）
❌ 不要在应用商店下载
手机自带应用商店、华为、小米应用商店里的 Termux 基本都是旧版本、阉割版、停止维护版，会出现：
- 源失效
- 安装软件报错
- 打不开、闪退
✅ 官方唯一推荐下载
去 F-Droid 官网下载最新原版 Termux。
安装完成打开，首次打开会自动初始化环境，等待几分钟即可。

---
三、首次开机必做初始化配置
第一次进入终端，必须先更新系统软件源，不然所有软件都装不了。
1. 更新系统索引和升级全部包
pkg update && pkg upgrade -y
过程中遇到询问全部按回车或选 y 即可。
2. 安装基础必备工具合集
pkg install -y vim curl wget git tree nano
包含编辑文件、下载文件、克隆代码、查看目录等日常必备命令。

---
四、Termux 访问手机本地存储（读写相册/下载/文件）
默认情况下 Termux 隔离运行，无法读取手机内部文件，需要手动授权。
执行授权命令
termux-setup-storage
弹窗点击允许授权。
授权后自动生成目录对应关系
- storage/downloads 手机下载文件夹
- storage/dcim 手机相册截图
- storage/shared 手机内部存储根目录
以后电脑传文件、手机放脚本都可以在这里互传。

---
五、Termux 常用包管理命令对照表
Termux 不是 Ubuntu，不要用 apt，统一用 pkg。
功能说明
命令
更新软件源
pkg update
升级所有软件
pkg upgrade -y
安装软件
pkg install 软件名
卸载软件
pkg uninstall 软件名
搜索软件
pkg search 关键词

---
六、常用开发环境一键安装
1. Python 环境（含 pip）
pkg install -y python python-pip
2. Node.js 前端/脚本环境
pkg install -y nodejs
3. C/C++ 编译开发环境
pkg install -y clang gcc make
4. 网络调试工具
pkg install -y openssh nmap net-tools

---
七、终端美化：安装 Oh My Zsh
默认终端不好看、没有自动补全，推荐装 zsh 美化。
sh -c "$(curl -fsSL https://raw.githubusercontent.com/ohmyzsh/ohmyzsh/master/tools/install.sh)"
安装完成自动切换美化终端，命令行更好看、操作更舒服。

---
八、SSH 远程连接电脑控制手机 Termux
可以在电脑 CMD / 终端直接操控手机 Termux，投屏级远程管理。
1. 安装 SSH 服务
pkg install -y openssh
2. 设置登录密码
passwd
3. 启动 SSH 服务
sshd
4. 查看手机局域网 IP
ifconfig
5. 电脑连接命令
ssh 用户名@手机IP -p 8022
Termux 默认 SSH 端口：8022。

---
九、Termux 后台保活防被杀后台设置
安卓手机后台限制严格，长时间挂机脚本容易被杀掉。
简单设置：
1. 手机电池设置 → 给 Termux 后台无限制
2. 锁定后台任务，不清理
3. 需要长期挂服务可搭配 nohup 后台运行

---
十、常见问题快速排查
1. 安装软件失败、源报错
重新执行：
pkg update && pkg upgrade
2. 读取不到手机文件
重新执行授权：
termux-setup-storage
3. SSH 连不上
- 确认手机电脑同一局域网
- 确认 sshd 已启动
- 端口必须带 -p 8022

---
结语
Termux 不只是一个终端软件，更是一台随身携带的小型 Linux 电脑。
学会基础用法，手机就能写代码、跑脚本、做测试、搭服务，随时随地折腾，不用带电脑也能干活。
