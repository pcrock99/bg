Jekyll 极简博客搭建教程｜全程GitHub网页手动操作，不用电脑本地部署，零配置一键建站

前言
很多人以为搭建个人博客要装环境、装 Git、装 Ruby、折腾命令行，特别麻烦。
其实Jekyll + GitHub Pages 根本不需要本地电脑任何环境，全程只用浏览器网页点一点，手机也能操作，几分钟就能拥有自己的个人技术博客。
写完文章直接网页新建文件、粘贴、提交，自动编译、自动发布、秒上线。
这篇就是全网最简单、零门槛、纯网页手动搭建 Jekyll 博客教程。

---
一、Jekyll + GitHub Pages 原理一句话看懂
- GitHub Pages：免费静态网页托管，永久免费，自带 HTTPS。
- Jekyll：GitHub 内置自动编译引擎，不用你装任何东西。
- 写作方式：只需要写 Markdown 文件，GitHub 自动帮你生成博客网站。
- 全程操作：全部在 GitHub 网页完成，不需要下载任何软件。

---
二、第一步：注册 GitHub 账号
没有 GitHub 先去官网注册一个，免费注册，简单填写信息即可。
地址：github.com

---
三、第二步：创建博客专属仓库（关键步骤）
1. 点击右上角 New repository 新建仓库
2. 仓库名字必须严格按格式填写
用户名.github.io
举例：
如果你的 GitHub 名字叫 abc123
仓库名就必须写：abc123.github.io
3. 配置选项
- Public 公开仓库（必须选）
- 勾选 Add a README file
- 其他默认不用改
点击创建，博客基础仓库就建好。

---
四、第三步：上传 Jekyll 基础主题配置（网页手动创建）
不用下载模板，我们直接网页手动创建核心配置文件。
1. 创建博客核心配置文件 _config.yml
仓库首页点 Add file → Create new file
文件名填写：_config.yml
粘贴下面极简配置：
title: 我的个人技术博客
description: 记录折腾、学习、笔记、教程
baseurl: ""
url: "https://你的用户名.github.io"

# 极简主题默认自带
theme: minima

# 开启目录、标签、文章功能
markdown: kramdown
permalink: /:year/:month/:day/:title/

拉到最下面 Commit 提交保存。

---
五、第四步：创建第一篇博客文章（网页直接写）
所有文章必须放在 _posts 文件夹里。
1. 新建文件夹 _posts
Add file → Create new file
文件名输入：_posts/2026-05-03-first-blog.md
格式必须：年-月-日-文章标题.md
2. 文章内容模板直接粘贴
---
layout: post
title: 我的第一篇 Jekyll 博客文章
date: 2026-05-03 00:00:00 +0800
categories: 日常随笔
tags: Jekyll 博客入门
toc: true
---

## 哈喽，我的极简博客搭建成功啦！

这是我在 GitHub + Jekyll 搭建的个人免费博客，全程网页操作，不用电脑本地环境，简单又好用。

以后所有技术笔记、折腾教程、生活随笔，全部都在这里记录！

3. 提交发布
直接拉到最下面 Commit 提交，GitHub 自动开始编译。

---
六、第五步：开启 GitHub Pages 网页访问
1. 仓库点 Settings 设置
2. 往下找到 Pages 选项
3. Branch 选择：main
4. 路径选择：/root
5. 保存
等待 1-3 分钟，浏览器打开：
https://你的用户名.github.io
博客直接就能打开访问！

---
七、以后写新文章固定操作（超级简单）
以后每次写笔记、写教程，只需要：
1. 仓库里进入 _posts 文件夹
2. 新建文件：年-月-日-自定义标题.md
3. 复制文章头部格式
4. 粘贴内容
5. 提交自动发布
不用编译、不用命令、不用电脑，手机浏览器就能写博客。

---
八、优点总结
- ✅ 全程网页操作，零本地环境
- ✅ GitHub 免费永久托管
- ✅ 自动 HTTPS 安全访问
- ✅ 写文章只需新建文件粘贴
- ✅ 适合放技术笔记、折腾教程、个人存档

---
结语
Jekyll + GitHub Pages 就是极简党最佳博客方案，不用花钱、不用维护、不用服务器、不用折腾环境。
